# 2. VISION

L'Afrique dispose d'une capacité de production considérable, particulièrement dans :

- l'agriculture ;
- l'agroalimentaire ;
- les matières premières transformées ;
- l'industrie légère ;
- les produits manufacturés ;
- l'artisanat et les produits spécialisés.

Cependant, une grande partie de cette capacité reste difficilement accessible aux acheteurs africains et internationaux.

Le problème n'est pas uniquement l'absence de marketplace.

Le véritable problème est la fragmentation de toute la chaîne :

**Production**

→ **Collecte**

→ **Agrégation**

→ **Qualité**

→ **Origine**

→ **Documentation**

→ **Conformité**

→ **Contrat**

→ **Logistique**

→ **Export**

→ **Transport**

→ **Réception**

→ **Paiement**

→ **Settlement**

→ **Litiges**

THE GATE vise à devenir :

> **la porte numérique du commerce africain vers l'Afrique et vers les marchés mondiaux.**

---

# 3. MISSION

La mission de THE GATE est de permettre à :

### un petit producteur

de participer à une transaction internationale sans devoir maîtriser toute la complexité du commerce extérieur ;

et à :

### un acheteur international

de pouvoir acheter une capacité de production africaine vérifiée, regroupée, conforme, traçable et livrable.

Le principe fondateur est :

> **Le producteur apporte la capacité de production. THE GATE apporte l'infrastructure commerciale et numérique qui permet de transformer cette capacité en transaction.**

# 4. PROBLÈME STRUCTUREL DU COMMERCE AFRICAIN

## Côté producteur

Le producteur peut avoir :

- le produit ;
- une capacité de production ;
- une qualité correcte ;

mais pas nécessairement :

- l'accès au marché ;
- l'expertise export ;
- la capacité documentaire ;
- la logistique ;
- les moyens financiers ;
- une capacité de négociation internationale.

## Côté acheteur

L'acheteur doit souvent :

- rechercher plusieurs fournisseurs ;
- vérifier leur existence ;
- vérifier leur capacité ;
- évaluer leur qualité ;
- consolider les volumes ;
- gérer plusieurs contrats ;
- gérer plusieurs documents ;
- organiser l'export ;
- gérer plusieurs paiements ;
- contrôler la marchandise ;
- gérer les réclamations.

THE GATE réduit cette fragmentation.

# 13. CONCEPT CENTRAL : MASTER TRADE ORDER

Une demande commerciale importante doit pouvoir être représentée par un :

# Master Trade Order

Exemple :

> Acheteur chinois  
> 5 000 tonnes de sésame  
> Livraison coordonnée en Chine

Pour l'acheteur, il s'agit d'une seule opération commerciale.

---

# 14. COMMERCIAL MASTER LOT

Le Master Trade Order peut produire :

# Commercial Master Lot

Exemple :

**5 000 tonnes**

Ce lot représente le besoin commercial global.

Mais il ne doit jamais faire disparaître les différentes origines.

---

# 15. ORIGIN SUB-LOTS

Le Commercial Master Lot contient des :

# Origin Sub-Lots

Exemple :

```text
MASTER TRADE LOT
5,000 tonnes

├── Cameroon Sub-Lot
│      1,000 t
│
├── Chad Sub-Lot
│        800 t
│
├── Nigeria Sub-Lot
│      1,200 t
│
├── Ghana Sub-Lot
│        900 t
│
├── Benin Sub-Lot
│        600 t
│
└── Burkina Faso Sub-Lot
         500 t
```

Chaque Sub-Lot possède son identité propre.

---

# 16. POURQUOI LES ORIGIN SUB-LOTS SONT STRATÉGIQUES

- origine ;

- documents ;
- certificats ;

> **une commande peut être commerciale­ment unique sans que la traçabilité juridique, physique et réglementaire soit fusionnée.**

# 17. LE LEAD TRADE INTEGRATOR

Pour une transaction multi-pays, THE GATE doit désigner ou enregistrer :

# Lead Trade Integrator — LTI

Le LTI est le responsable de l'orchestration opérationnelle.

Il coordonne :

- fournisseurs ;
- agrégateurs ;
- collecte ;
- consolidation ;
- inspections ;
- documents ;
- logistique ;
- export.

THE GATE fournit l'infrastructure numérique.

Le LTI fournit l'exécution opérationnelle.

# 18. ONE COMMERCIAL DELIVERY ≠ ONE PHYSICAL CONTAINER

> **One Delivery**

ne signifie pas nécessairement :

> **One Container containing mixed-origin bulk goods.**

# 27. RÈGLE SHARIAH SUR LES REVENUS

La plateforme ne doit pas gagner de l'argent :

> **parce que l'argent reste immobilisé.**

Elle gagne :

> **parce qu'elle fournit un service réel.**

Sont exclus du modèle :

- intérêt ;
- rendement du float ;
- intérêts sur wallet ;
- prêt conventionnel à intérêt ;
- courtage de prêt conventionnel ;
- commission d'assurance conventionnelle.

Les structures conformes devront être revues selon la gouvernance Shariah retenue.
